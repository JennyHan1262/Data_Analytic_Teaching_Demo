# Publishing Checklist

- [ ] Repo name is lowercase-with-hyphens and descriptive
- [ ] README follows the standard structure (question, data, approach, findings, reproduce)
- [ ] Folder layout matches the template
- [ ] Raw data is public/anonymized, or excluded via `.gitignore`
- [ ] No passwords, API keys or client data committed
- [ ] Code runs from a clean environment (`requirements.txt` present)
- [ ] At least one chart embedded in the README
- [ ] Meaningful commit messages
- [ ] "About" description and topics set
- [ ] Repo pinned on your profile
